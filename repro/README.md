# Replay

Use Node 26, Python 3, and Codex CLI 0.159.2. Create detached stock and patched checkouts at the revisions in the report, install their locked dependencies, and apply the corresponding observation-only diff. Set STOCK_TREE and PATCHED_TREE to those checkouts, CODEX_BINARY to the Codex executable, and OPENAI_API_KEY to an existing authorized OpenAI API credential. Run `python3 run.py stock-r2 patched-r2 stock-r3 patched-r3`. Each label must be new. The script uses empty, independent homes, workspace, state, compile cache and Codex homes, a dynamically allocated loopback port, and process-owned cleanup.

`client.mjs` sends the owner turns through a real Gateway client. Turn 2 requests cleanup=keep to retain the child policy for inspection. The persistent global exec denial is inherited by the child; additional child-only denials are configured separately. `codex-wire.py` transparently forwards JSON-RPC and redacts credentials before recording. The observation-only source diff logs the existing per-attempt restriction fields; it does not change decisions or state. `extract.py` correlates actual turn/start requests, native rollout token_count events, task completion answers and independent SQLite snapshots.
